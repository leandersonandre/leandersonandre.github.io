      Questões sobre Funções

      Questão 1
      O que é uma função em Python?
    • A. Uma unidade de código que encapsula uma tarefa ou operação específica.
    • B. Uma estrutura utilizada exclusivamente para armazenar números.
    • C. Uma variável que pode armazenar apenas textos.
    • D. Um comando utilizado exclusivamente para realizar cálculos matemáticos.
      • Resposta correta: A
      Uma função é uma unidade de código que encapsula uma tarefa ou operação específica e pode ser reutilizada ao longo de um programa.
      Questão 2
      Qual palavra-chave é utilizada para definir uma função em Python?
    • A. `function`
    • B. `def`
    • C. `func`
    • D. `define`
      • Resposta correta: B
      A palavra-chave `def` é utilizada para definir uma função em Python.
      Questão 3
      Analise o código abaixo. Qual é o nome da função? 
      
def somar(a, b):
    r = a + b
    return r

    • A. `def`
    • B. `somar`
    • C. `a`
    • D. `r`
      • Resposta correta: B
      O nome da função é `somar`. A palavra `def` é a palavra-chave utilizada para definir a função.
      Questão 4
      No código abaixo, quais são os parâmetros da função? 
      
def somar(a, b):
    r = a + b
    return r

    • A. `def` e `somar`
    • B. `a` e `b`
    • C. `r`
    • D. `a`, `b` e `r`
      • Resposta correta: B
      Os parâmetros são `a` e `b`, definidos entre os parênteses após o nome da função.
      Questão 5
      Analise o código abaixo. O que será impresso? 
      
def hello():
    print("Hello Função")

hello()

    • A. Nada será impresso.
    • B. `hello`
    • C. `Hello Função`
    • D. Ocorrerá um erro porque a função não possui parâmetros.
      • Resposta correta: C
      A função é definida e depois chamada por meio de `hello()`. Quando chamada, seu corpo é executado e imprime `Hello Função`.
      Questão 6
      A definição de uma função em Python executa imediatamente o seu corpo?
    • A. Sim, sempre.
    • B. Não. O corpo é executado quando a função é chamada.
    • C. Somente se a função possuir parâmetros.
    • D. Somente se a função possuir `return`.
      • Resposta correta: B
      A definição da função não executa seu corpo. As instruções são executadas quando a função é chamada.
      Questão 7
      Analise o código abaixo. Qual valor será associado ao parâmetro `nome`? 
      
def hello(nome):
    print("Olá,", nome)

hello("Pernalonga")

    • A. `hello`
    • B. `nome`
    • C. `"Pernalonga"`
    • D. `"Olá,"`
      • Resposta correta: C
      Na chamada `hello("Pernalonga")`, o argumento `"Pernalonga"` é associado ao parâmetro `nome`.
      Questão 8
      No código abaixo, o que representa o valor `10`? 
      
def somar(a, b):
    print(a + b)

somar(10, 20)

    • A. O nome da função.
    • B. Um parâmetro.
    • C. Um argumento.
    • D. O corpo da função.
      • Resposta correta: C
      `10` é um argumento fornecido durante a chamada da função. Ele será associado ao parâmetro `a`.
      Questão 9
      Analise o código abaixo. O que será impresso? 
      
def somar(a, b):
    r = a + b
    print("Resultado =", r)

somar(4, 5)

    • A. `Resultado = 4`
    • B. `Resultado = 5`
    • C. `Resultado = 9`
    • D. `Resultado = 20`
      • Resposta correta: C
      O parâmetro `a` recebe `4` e `b` recebe `5`. Portanto, `r` será `4 + 5`, resultando em `9`.
      Questão 10
      Em uma chamada de função utilizando argumentos posicionais, como os valores são associados aos parâmetros?
    • A. Pelo tipo dos valores.
    • B. Pela posição em que os argumentos são informados.
    • C. Pelo tamanho dos nomes dos parâmetros.
    • D. Pela ordem alfabética dos parâmetros.
      • Resposta correta: B
      Nos argumentos posicionais, os valores são associados aos parâmetros pela posição em que aparecem na chamada da função.
      Questão 11
      Analise o código abaixo. Qual valor será associado ao parâmetro `idade`? 
      
def apresentar(nome, idade):
    print("Nome:", nome)
    print("Idade:", idade)

apresentar("Pernalonga", 5)

    • A. `"Pernalonga"`
    • B. `5`
    • C. `nome`
    • D. `idade`
      • Resposta correta: B
      Como os argumentos são posicionais, `"Pernalonga"` é associado a `nome` e `5` é associado a `idade`.
      Questão 12
      Qual chamada utiliza corretamente argumentos nomeados para a função abaixo? 
      
def apresentar(nome, idade):
    print("Nome:", nome)
    print("Idade:", idade)

    • A. `apresentar("Pernalonga", 5)`
    • B. `apresentar(nome="Pernalonga", idade=5)`
    • C. `apresentar(nome, idade)`
    • D. `apresentar("nome=Pernalonga", "idade=5")`
      • Resposta correta: B
      Na chamada `apresentar(nome="Pernalonga", idade=5)`, os argumentos são associados explicitamente aos parâmetros pelos seus nomes.
      Questão 13
      Analise o código abaixo. O que será impresso? 
      
def apresentar(nome, idade):
    print("Nome:", nome)
    print("Idade:", idade)

apresentar(idade=5, nome="Pernalonga")

    • A. `Nome: 5` e `Idade: Pernalonga`
    • B. `Nome: Pernalonga` e `Idade: 5`
    • C. `Nome: nome` e `Idade: idade`
    • D. Ocorrerá um erro porque a ordem está invertida.
      • Resposta correta: B
      Como os argumentos são nomeados, a ordem pode ser alterada. `nome` recebe `"Pernalonga"` e `idade` recebe `5`.
      Questão 14

def apresentar(nome, idade=18):

    print("Idade:", idade)

      O que será impresso pela chamada abaixo? 
      
apresentar("Pernalonga")

    • A. `Nome: Pernalonga` e `Idade: 18`
    • B. `Nome: Pernalonga` e `Idade: 0`
    • C. `Nome: 18` e `Idade: Pernalonga`
    • D. Ocorrerá um erro porque `idade` não foi informada.
      • Resposta correta: A
      Como nenhum argumento foi fornecido para `idade`, será utilizado o valor padrão `18`.
      Questão 15
      Considere a função: 
      
def apresentar(nome, idade=18):
    print("Nome:", nome)
    print("Idade:", idade)

      O que será impresso pela chamada abaixo? 
      
apresentar("Pernalonga", 5)

    • A. `Nome: Pernalonga` e `Idade: 18`
    • B. `Nome: Pernalonga` e `Idade: 5`
    • C. `Nome: 5` e `Idade: Pernalonga`
    • D. Ocorrerá um erro porque existe um valor padrão.
      • Resposta correta: B
      Quando um argumento é fornecido, ele substitui o valor padrão. Portanto, `idade` recebe `5`.
      Questão 16
      Analise o código abaixo. Quantos argumentos podem ser fornecidos na chamada da função? 
      
def somar(*numeros):
    resultado = 0
    for numero in numeros:
        resultado += numero
    print(resultado)

    • A. Exatamente um.
    • B. Exatamente dois.
    • C. Uma quantidade variável de argumentos.
    • D. Nenhum argumento.
      • Resposta correta: C
      O parâmetro precedido por `*` permite que a função receba uma quantidade variável de argumentos.
      Questão 17
      Analise o código abaixo. Qual é o tipo de estrutura que armazena os valores recebidos por `*numeros`? 
      
def somar(*numeros):
    resultado = 0
    for numero in numeros:
        resultado += numero
    print(resultado)

    • A. Lista
    • B. Dicionário
    • C. Tupla
    • D. String
      • Resposta correta: C
      Os argumentos recebidos por um parâmetro precedido por `*` são agrupados em uma tupla.
      Questão 18
      Analise o código abaixo. O que será impresso? 
      
def somar(*numeros):
    resultado = 0
    for numero in numeros:
        resultado += numero
    print(resultado)

somar(1, 2, 3)

    • A. 3
    • B. 5
    • C. 6
    • D. 123
      • Resposta correta: C
      Os argumentos `1`, `2` e `3` são agrupados em `numeros`. O laço soma os valores, resultando em `6`.
      Questão 19
      Qual é a finalidade do parâmetro precedido por ** em uma função Python?
    • A. Receber uma quantidade variável de argumentos posicionais.
    • B. Receber uma quantidade variável de argumentos nomeados.
    • C. Definir um valor padrão.
    • D. Impedir que a função receba argumentos.
      • Resposta correta: B
      Um parâmetro precedido por `**` permite receber uma quantidade variável de argumentos nomeados.
      Questão 20
      Analise o código abaixo. Qual é o tipo de estrutura que armazena os argumentos recebidos por `**dados`? 
      
def apresentar(**dados):
    for chave, valor in dados.items():
        print(chave, "=", valor)

    • A. Lista
    • B. Tupla
    • C. String
    • D. Dicionário
      • Resposta correta: D
      Os argumentos nomeados recebidos por `**dados` são agrupados em um dicionário.
      Questão 21
      Analise o código abaixo. O que será impresso? 
      
def apresentar(**dados):
    for chave, valor in dados.items():
        print(chave, "=", valor)

apresentar(nome="Pernalonga", idade=5)

    • A. `nome = Pernalonga` e `idade = 5`
    • B. `Pernalonga = nome` e `5 = idade`
    • C. `nome = 5` e `idade = Pernalonga`
    • D. Nada será impresso.
      • Resposta correta: A
      Os argumentos nomeados são armazenados no dicionário `dados`. O laço percorre as chaves e os valores, imprimindo `nome = Pernalonga` e `idade = 5`.
      Questão 22
      Analise o código abaixo. Qual alternativa apresenta uma chamada válida para a função? 
      
def somar_tres(a, b, c):
    r = a + b + c
    print("Resultado =", r)

    • A. `somar_tres(3, 7)`
    • B. `somar_tres(3, 7, 8)`
    • C. `somar_tres(3)`
    • D. `somar_tres()`
      • Resposta correta: B
      A função possui três parâmetros obrigatórios: `a`, `b` e `c`. Portanto, a chamada deve fornecer três argumentos.
      Questão 23
      Analise o código abaixo. O que será impresso? 
      
def somar_tres(a, b, c):
    r = a + b + c
    print("Resultado =", r)

somar_tres(3, 7, 8)

    • A. `Resultado = 15`
    • B. `Resultado = 18`
    • C. `Resultado = 21`
    • D. `Resultado = 24`
      • Resposta correta: C
      Os parâmetros recebem `a = 3`, `b = 7` e `c = 8`. Assim, `3 + 7 + 8 = 18`.
