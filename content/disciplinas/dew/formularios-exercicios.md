{{< questao >}}

Crie uma página em HTML que apresenta um formulário para selecionar uma cidade.
O formulário deverá apresentar um campo do tipo `select` para selecionar o estado. Conforme o Estado for selecionado,
em um campo do tipo `datalist`, deverá apresentar as cidades com a funcionalidade de `autocomplete`. Utilize a propriedade `onChange` do select para mudar a lista de valores do `datalist`.

{{< /questao >}}
